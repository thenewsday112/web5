PHP2Shell and eMudhra Patched

📅 Oct 23, 2026  |  Category: Other  |  Read Source →

Two security events landed side by side this week, PHP2Shell and the eMudhra certificate compromise. Both reached the same place, the foundation their applications are built on.

PHP2Shell is a pair of critical flaws in the PHP engine itself, CVE-2026-109618 and CVE-2026-109619. They let an unauthenticated request become code execution on the server, on any PHP application, however careful its own code is, and PHP runs about 69% of the websites whose server-side language is known.

The eMudhra compromise is a different kind of problem. Eight intermediate certificates from the certificate authority eMudhra turned out to have private keys that can be computed from the public certificates, which let anyone issue a certificate for any website and have it accepted. Browsers revoke certificates like these on their own, but a container image carries its own trust store and keeps trusting them until it is rebuilt.

Docker Hardened Images published a fixed PHP image within 24 hours

The dhi.io/php image was rebuilt on the patched PHP and published early on October 22, within 24 hours of the upstream release and after the DHI testing and verification steps. Pulling the current tag puts you on the fixed version. The few DHI images that bundle their own PHP application, such as composer and nextcloud, follow as their upstream projects release.

Rebuilt across the catalog, verifiable tag by tag

The certificate compromise touched the whole catalog, because every image carries a trust store. In the 48 hours after the PHP release, the DHI build system ran 16,567 package and image builds across the catalog. By 10pm UTC on October 22, almost all catalog tags were on the fixed CA store, with most of the rest in the build queue. That percentage comes from the SBOM that ships with every image, read for every published tag to check which CA store and which PHP version it carries, and you can run the same check on anything you pull.

How to make sure your environments are covered

If you run PHP on Docker Hardened Images, pull the current tag for your branch and redeploy, and rebuild anything you built on top of a DHI image so it picks up the new base docker pull dhi.io/php:8.4

Customizations built through the DHI Enterprise workflow are rebuilt automatically when the base layer is patched. For the certificate fix the same applies to every image you build from a DHI base, PHP or not. The Docker Security update from October 22 lists the affected PHP versions and the support path.

If you run PHP in any other container, check the PHP version running inside it rather than the tag on the outside, and rebuild it on a patched base.

Build from a trusted foundation

Weeks like this one will keep coming, but a trusted foundation will make all the difference.

If you are not building on hardened images yet, this week is the wake-up call and the week to start. Both events landed on the foundation, and that is where the fix has to happen, in the image itself, rebuilt from fixed sources before anyone pulls it.

This is exactly what Docker Hardened Images were built for. Docker builds, patches and maintains the system packages inside each image from source, and the build system is event-driven, so an upstream release or a changed package triggers rebuilds of everything that depends on it. Each image ships signed, with its SBOM, SLSA Build Level 3 provenance and VEX data attached, which is why a rebuild of this size can be measured as well as done.

The catalog is free and open source under Apache 2.0, with near-zero CVEs on every image. It stays compatible with the Alpine and Debian your teams already run, so adoption is a one-line change to the FROM line in your Dockerfile, with no migration project attached. DHI Select and DHI Enterprise add SLA-backed remediation with critical CVE fixes within 7 days, FIPS and STIG variants, image customization with the guarantees kept, and Extended Lifecycle Support for the versions upstream has stopped patching. All of it is in the Docker Hardened Images catalog, free to pull today.

Accordion Icons: Which Work Best?

📅 Oct 23, 2026  |  Category: Other  |  Read Source →

So what icon is the most reliable to show expansion and collapsing for accordions? Is there really any noticeable difference between carets, chevrons, arrows, and triangles?

Well, research shows that there is some difference indeed. But what’s more interesting is that split menus are harmful, why it's better to not have icons and text labels link to different actions, and why the caret is the safest icon choice. Let’s dive in!

No Icon = Opening The Page

The findings aren’t very surprising: without any icon in use, users expect that tapping on the menu item would take them directly to a new page. Users often struggle with custom icons as they don't clearly signal that they'll open an accordion. And people tend to tap fairly equally on the icon and on the label for most icons.

Many designs (like the one below) tend to slightly overcomplicate things by adding arrows and carets pointing everywhere, depending on the state of the accordion. But typically we don't need to use an arrow to indicate a link to the category.

The rule of thumb is very simple: if it’s a link, the easiest and most effective way is to simply underline it — without any arrow, caret, or other icon. Perhaps it’s not particularly exciting, but it works flawlessly every single time.

Confusing Behavior With Arrows ▶ and Split Buttons

Using a right-facing arrow icon ▶ isn’t associated with an expectation of going directly to a new page. And having the same icon pointing down ▼ doesn’t necessarily imply that an accordion is going to open on tap/click.

It’s a good idea to avoid split buttons for accordions — where the text label links directly to a page, but the icon opens the accordion. Instead, it’s much more reliable to allow users to tap on a main category and expose the menu; and to access the category page, we add a link to it inside the menu.

Plus +/− and Arrows ↓/↑ Are Understood, But Can Be Misunderstood

For accordions, we typically use +/− or arrows ↓/↑ to signal expanded and collapsed states, and typically it works well. However, both have many different interpretations. Plus + can mean anything from saving for later to adding to cart to zooming in, and can be particularly confusing for multi-level navigation, with many levels open at the same time.

Arrows ↓/↑ can mean scrolling or sliding or finding the next match, but also a jump to a particular portion of a page. Both plus and arrows are well-understood and work, but depending on the design, can be confusing — mostly because they are overloaded.

Wrapping Up

The safe choice is to use the caret/triangle pointing down ▼ by default, and change it to a caret pointing up or a caret pointing sideways ▶ on interaction. If you need an alternative, then +/- typically work well, too.

But we certainly don’t need any further icons or arrows to indicate where the links go. The same goes for split menus, which often produce more mistakes than help. Instead, we have one button or dropdown that does exactly one thing — shows all options and allows users to drill down.

And if you need a direct link, we link the title directly to the page and underline it. More often than not, simpler is better.

What’s Important to Us When Making Political Decisions?

📅 Oct 23, 2026  |  Category: Science  |  Read Source →

A core assumption in any democracy is that citizens with access to information will make reasoned decisions on political candidates and policy issues. But a new study by UC Berkeley social scientists finds that Americans usually don’t consider the full scope of difficult issues, instead basing their opinions on mental shortcuts that sidestep complexity.

The paper offers striking insight into the differences in cognitive reasoning patterns among Americans. While some people in the study did closely analyze a range of issues before coming to an opinion, others did a quick back-of-the-napkin tally of plusses and minuses, or even more commonly based their opinions on just one factor, the authors found.

“When people make complicated choices with many considerations—which political candidate to support, which immigrant they would rather admit to the country, which climate policy they prefer—we tend to assume they’re weighing all the factors,” said Berkeley political scientist Kirk Bansak. But, he added, “we find that most of them aren’t. Most commonly, people rely on a mental shortcut, effectively deciding based on the single factor they care about most and largely ignoring the rest.”

For example, when asked to choose between two fictional U.S. Senate candidates based on age, gender, race, education, military experience, and political experience, many of the study participants would make their decision based on just one of those factors.

That doesn’t mean that people are irrational, said coauthor Nidhi Banavar, a Berkeley cognitive scientist. “The kind of rationality that we define in the paper is quite different from what many humans actually do in real life,” she explained. “We have these amazing brains, but they’re not the infinite computational machines that would be necessary in order to do the kind of ‘rational’ we imagine in our paper.”

Still, the findings have clear implications for politics and political communication. For example, Banavar said, if a leader knows that public opinion on climate change is dominated by pocketbook concerns to the exclusion of other issues, then that single factor might weigh heavily in political advertising. Complex science issues, meanwhile, might be downplayed.

The paper, “Classifying Strategy Use in Multi-Attribute Subjective Choice: Application to Conjoint Experiments in Political Science,” was published recently in Proceedings of the National Academy of Sciences. Bansak is an associate professor of political science at UC Berkeley; Banavar is a postdoctoral researcher in political science at UC Berkeley.

The foundational ideals of American democracy grew from the Enlightenment era some three centuries ago. Central to that framework was a belief that humans, being rational, are capable of governing themselves—and justified in demanding political power. A core concept has been the marketplace of ideas, a constant competition between political and policy goals, plans, and analysis that would inform citizens and help them to govern themselves.

While many eras in U.S. history feature episodes in which reason faltered, modern social scientists have detailed the ways in which cognitive bias, rational ignorance, and other behaviors short-circuit reasoning. Still, the hopeful assumption about human reasoning persists.

Deep patterns in decision making

Social scientists have long studied human decision making at the aggregate level. Banavar and Bansak set out to build a new kind of cognitive model, a complex tool that can enable researchers to see an individual’s decision making mid-process, in detail.

The model doesn’t give them a view into the minds of their research subjects, but the researchers can study hundreds or thousands of decisions by an individual; from these patterns, they can perceive the values and reasoning processes that shape their decisions.

In all, nearly 3,800 people were involved in the study. Each participant sat at a computer screen, and the computer generated a random set of choices in three areas: which migrants they would rather admit to the United States, which Senate primary candidate they would rather vote for, and which climate policy package they would prefer the United States to adopt.

Consider the basic question comparing two hypothetical migrants to the U.S. Their profiles appeared side by side, each described by six factors: region of origin, education level, gender, age, English proficiency, and whether they were seeking economic opportunity or asylum. The research subject would have to choose which of the migrants they preferred to admit to the U.S.

The computer randomly presented 30 different sets of hypothetical migrants. If a participant consistently chose the younger migrant or the migrant with greater English skills, for example, the researchers could conclude that that was the most important factor for that participant.

The same decision framework was presented for comparing potential climate change policies and fictional U.S. Senate candidates.

The research did yield some insights about basic priorities: Participants preferred younger political candidates. They preferred climate change policy that minimized economic impact on their household. They preferred immigrants who were seeking asylum as opposed to seeking economic opportunity, and those who were below retirement age.

But that wasn’t the primary purpose of the study. Banavar and Bansak were less interested in what participants decided, and more interested in how they decided.

Thoughtful reflection or hot takes?

The results were striking: In 68% of the cases, study participants used shortcuts and did not deeply assess all six factors when choosing between hypothetical Senate candidates, migrants, or climate policies.

Nearly 54% showed a pattern of making choices dominated by one of the six factors. Another 14% took a different shortcut: Given six factors for each candidate or policy, they counted the total number of factors that they preferred for each, then chose the one containing the greater number.

How many used a comprehensive evaluation of all six factors—a rational assessment, without any shortcuts? Just under 30%.

Interestingly, Banavar said, a majority of participants did not consistently stay with the same strategy. Some might rely on just one factor in choosing a climate policy, while more fully weighing all the factors in deciding which migrant to admit.

“You can’t put people into buckets to say, ‘OK, this is someone who’s actually only going to care about only one thing,’” she said. “People are actually relating differently to each of these different domains and choosing to use different levels of effort, for want of a better term.”

To understand why people shift strategies will require further research, she said.

The study comes with some important caveats: If a participant favored female candidates, for example, or migrants who were seeking political asylum, and if both choices had those attributes, the participants had to consider other factors. That reduced, but did not eliminate, the pattern of making a choice based on one factor.

But when the researchers asked the participants to rate each profile before choosing one of them, the participants were more inclined to consider all factors in making their choices.

Further, the researchers allowed for only two attributes in their comparisons—male or female, for example, white or Black, or aged in their 50s or 70s. That’s not ideal, Banavar said, but to include multiple races, for example, is too complex for the cognitive model, and would dilute the patterns in the data. In the choice of Senate candidates, the study did not include the fictional candidates’ political parties. That question could provoke such strong, reflexive reactions that it would cloud the findings, she said.

Implications for real-world politics

The authors say their research has important implications not just for cognitive research, but for real-world, on-the-ground U.S. political processes.

Often, Bansak said, our understanding of public opinion is based on surveys that ask people to choose between complex options defined by many factors. The new research shows analysts that individuals often base their opinions on a single factor, and that can create a clearer picture of what people want in public policy, and why they want it.

“This bears directly on how we interpret the kind of public-opinion and preference data that routinely informs policy debates and news coverage,” he said.

And that understanding, Banavar said, can shape the policy process—and political communication. If leaders present issues in layers of complexity, “how much are people going to read or listen to that?” she asked. “What is the thing that’s really important to them, given a particular issue? That’s completely lost when you don’t think about the decision-making process.”

How to stop nightmares and fall back asleep after bad dreams

📅 Oct 23, 2026  |  Category: Entertainment  |  Read Source →

Clinically reviewed by Dr. Chris Mosunic, PhD, RD, CDCES, MBA

Nightmares can be a nightmare for your health and well-being. Find out what causes bad dreams to learn how to prevent them, and fall back to sleep more easily. 

Nightmares can be really tough. They jolt us awake in the middle of the night, often in a cold sweat with a racing heart, and the residue of the bad dream leaves us feeling shaken and on edge, making it hard to fall back asleep. And we all know how much more challenging everything else becomes when our sleep is disrupted.

Recurring nightmares can wreck your sleep and leave you feeling drained, anxious, or unsettled the next day. If you’ve found yourself googling, “why do I keep having nightmares?” or, “how to stop bad dreams every night,” you’re not alone.

Nightmares can be triggered by everything from stress and sleep disorders to late-night snacks or certain medications. Thankfully, there are proven strategies to reduce their frequency and help you get back to sleep after a bad dream.

Let’s explore common nightmare causes, tips to prevent them, and techniques to calm your mind and body when you wake up in the middle of the night.

 

The truth about nightmares

Sleep disruptions, like frequent nightmares and bad dreams, can take their toll on our well-being. It’s not just about feeling tired the next day. It’s about how those disturbances affect our mood, energy levels, productivity, and our mental health. Getting enough sleep is crucial when it comes to rejuvenating our bodies and resting our minds, but when you’re experiencing nightmares on the reg, peaceful sleep can feel like a distant dream. 

But there is hope. With awareness and understanding of what’s causing your nightmares, along with some effective strategies, it’s possible to manage, if not prevent, bad dreams. Tools such as mindfulness and meditation can help you cultivate a more peaceful mind and significantly improve the quality of your sleep.

What causes nightmares? 7 common reasons bad dreams happen

Nightmares don’t tend to be random. They’re usually the product of various factors at work in our subconscious or conscious minds. So a key factor in tackling nightmares is being able to understand what’s prompting them.

  1. Stress and/or anxiety: Perhaps unsurprisingly, frequent nightmares can be the product of stress or anxiety that’s present in our waking life. It’s like your mind extends the day’s worries into your sleep. That upcoming work presentation, conflict with your partner, or just the sheer weight of day-to-day tasks can all find their way into your dreams, causing nightmares.

  2. Eating too close to bedtime: That late-night snack might be more trouble than it’s worth. And no, it’s not just cheese, which, by the way, doesn’t actually cause nightmares. Heavy or spicy meals, in particular, can lead to physical discomfort that disturbs your sleep, often inducing vivid and sometimes bad dreams.

  3. Scary movies, TV shows, or books: Love a good horror movie or thriller book before bed? You might want to rethink that. Your subconscious can weave elements of the contents of whatever you’ve been reading or watching into your dreams, creating some pretty unsettling mental visualizations when the lights go off.

  4. Traumatic experiences: If you’ve been through a particularly challenging event either recently or in the past, the trauma of whatever happened could show up in your dreams. This is normal. It’s your brain’s way of processing the trauma, but it can lead to recurring nightmares, which can be distressing and even prevent sleep. 

  5. Alcohol, drugs, and/or caffeine: It may feel like alcohol and drugs ease you into sleep more easily than going to bed unassisted, but these substances often disrupt the quality of your sleep and can lead to vivid, intense nightmares.

  6. Medications: Some prescription drugs, including certain types of antidepressants, blood pressure medicines, and beta blockers, can lead to bad dreams. If you’ve started a new medication and are experiencing frequent nightmares, you might want to talk to your doctor.

  7. Sleep disorders: Sleep conditions like sleep apnea and restless leg syndrome can disrupt sleep and lead to nightmares. If you’re experiencing symptoms such as daytime sleepiness or morning headaches, please check in with a healthcare provider.

Knowing what triggers your nightmares is the first step in gaining control over them. Remember, the goal isn’t to eliminate all dreams but to cultivate a more relaxed sleep experience. After all, dreams are a natural part of sleep, and many of them can be magical, rejuvenating, and creative experiences. 

10 tips to prevent nightmares and stop bad dreams

Now that we know what might be causing nightmares, here are some strategies to help keep bad dreams at bay.

1. Establish a bedtime routine

Routines aren’t just for kids, and the value of a consistent sleep schedule can’t be overstated. Your body thrives on routine, so a regular sleep and wake time helps your body understand when it’s time to wind down and when it’s time to rise.

2. Create a sleep-friendly environment

Consider your sleeping environment. Is it dark, quiet, and cool? These are ideal conditions for restful sleep. Also, consider investing in a comfortable mattress and pillows. These small changes can significantly impact your sleep quality and help prevent bad dreams.

3. Take active steps to manage your stress during the day

If stress or anxiety is the culprit behind your nightmares, it’s important to tackle the cause head-on. Implementing stress management techniques, such as deep breathing exercises or guided mindfulness practices (such as this one), can work wonders in soothing your mind before bed.

4. Avoid stimulating activities before bed

Try to wind down at least an hour before bed. This means turning off the TV, stepping away from work, and switching off any other devices. This quiet time allows your mind to transition smoothly into sleep mode.

5. Exercise during the day

Regular physical activity can promote better sleep, helping to prevent nightmares. Just ensure you don’t exercise too close to bedtime, as it can have the opposite effect.

6. Avoid heavy meals before bed

As mentioned before, late-night snacking, especially heavy or very spicy food, can lead to bad dreams. Finish eating at least a few hours before hitting the hay.

7. Relax before falling asleep

Incorporate relaxing activities into your bedtime routine. This could include reading, listening to relaxing music, or practicing mindfulness exercises. It’s all about calming your mind and preparing your body for sleep.

8. Talk about whatever’s troubling you

If something’s bothering you, don’t let it stew in your mind. Talking it out with a trusted friend, family member, or professional can help release some of the burden.

9. Limit alcohol and caffeine

Both these substances can disrupt your sleep cycle and might increase the likelihood of having nightmares. Try limiting them or avoiding them altogether.

10. Review your medications

If you suspect your medication is causing nightmares, discuss it with your healthcare provider. They might be able to adjust the dosage or suggest alternatives.

Implementing these strategies can make a big difference in preventing nightmares and improving the overall quality of your sleep. Everyone deserves a good night’s sleep, and you’re no exception. Remember, it’s not about perfection but progress, so celebrate small victories and keep experimenting to find out what works best for you.

How to go back to sleep after a nightmare

The biggest challenge after waking up from a nightmare is often trying to calm your body and mind enough so you can get back to sleep. If you’ve ever found yourself wide awake at 3 a.m., staring at the ceiling, you know exactly what we’re talking about.

So how exactly do you drift back into the land of nod once you’ve been rudely awakened by a nightmare? Here are seven strategies that might help you fall back asleep after a bad dream.

1. Deep breathing exercises 

Deep, controlled breathing can be a powerful tool in helping to calm your mind and body. The practice works by shifting your focus away from any disturbing images from your nightmare and redirects it onto the rise and fall of your breath. An easy-to-follow technique is the 4-7-8 breathing method, where you inhale for 4 counts, hold your breath for 7 counts, and exhale for 8 counts.

2. Try progressive muscle relaxation

This technique involves tensing and then releasing different muscle groups in your body. Start from your toes and work up to your head (or vice versa). This can help you feel more grounded and take your mind off the images or content of your nightmare.

3. Visualize yourself somewhere soothing 

Picture a peaceful, calming scene. It could be a beautiful beach, a serene forest, or any place that brings you joy and tranquility. Focusing on images that make you feel relaxed and at ease can steer your mind away from whatever you were dreaming about.

4. Do something comforting

If you’re finding it hard to fall back asleep, get out of bed and do something relaxing. This could be reading a book, listening to calm music, or doing a low-intensity activity like drawing. Do whatever feels soothing to you, and try to do it somewhere quiet and in low-lighting so your body can ease into relaxation and sleep. If in doubt, try listening to a Sleep Story. 

5. Keep a night light on

If you wake up scared, turning on a soft, gentle light can feel comforting. In some ways, it feels like you’re banishing the darkness from your dream, and being able to see your surroundings makes you feel safer and more at ease. Just make sure its not too bright or it may, ironically, end up disrupting your sleep.

6. Keep a dream journal

Writing down whatever happened in your nightmare can be therapeutic. In some ways, the process of writing helps to drain away the power the bad dream has over your emotions. Keep a notebook and pen beside your bed and if a nightmare wakes you up, write it down. Here’s a Dream Journal you can download and print out.

7. Take a mindful moment

If you’ve been startled awake by a nightmare, take a moment to center yourself. Notice your surroundings, the feeling of the sheets, the sounds you can hear. This can bring you back to reality and help separate the images of your nightmare from the safety of your bedroom. Repeat to yourself: “I am here. I am safe.”

Finding it difficult to fall back to sleep after a nightmare is perfectly normal. Don’t pressure yourself to get back to sleep immediately. Take your time, be gentle with yourself, and use the techniques above to help guide your mind and body back into a state of ease.

Your questions about nightmares, answered

What triggers nightmares?

Nightmares can be triggered by a variety of factors. Common triggers include stress or anxiety, late-night eating, exposure to disturbing content like horror films or books, traumatic experiences, substance use like alcohol or drugs, certain medications, and sleep disorders.

What causes nightmares, and how do you prevent them?

Similar to the triggers mentioned above, these factors can cause nightmares. Preventing nightmares often involves addressing these underlying causes. This could mean establishing a healthy sleep routine, creating a sleep-friendly environment, managing stress, avoiding stimulating activities before bed, exercising regularly, avoiding heavy meals before bedtime, and talking about what’s troubling you. Remember that everyone’s different, and what works best for you might differ from what works best for others.

Is it okay to have nightmares every night?

While occasional nightmares are normal, having them every night is not typical and can be distressing. Frequent nightmares can interfere with your sleep quality and overall well-being. If you’re experiencing nightmares regularly, speaking to a healthcare provider or a mental health professional may be beneficial to identify any underlying issues that might need addressing.

Do you ever stop having nightmares?

Yes, many people experience nightmares less frequently as they age. However, some adults do continue to have nightmares. Addressing the underlying causes of nightmares, like stress or anxiety, can significantly reduce their frequency. Remember, occasional bad dreams are normal, but if they are causing significant distress or affecting your sleep, it’s worth discussing this with a healthcare provider.

Nightmares can be challenging, but understanding their triggers and implementing strategies to manage them can help you reclaim a peaceful night’s sleep. 

What causes nightmares to happen repeatedly?

Frequent nightmares can be caused by high stress levels, anxiety disorders, PTSD, sleep disorders like sleep apnea, or even certain medications. Alcohol and late-night eating can also disrupt REM sleep, where most nightmares occur. If they persist nightly, it might be worth speaking to a medical or mental health professional.

How can I stop having bad dreams every night?

To break the cycle of nightly nightmares, focus on improving sleep hygiene—stick to a consistent sleep schedule, avoid screens and heavy meals before bed, and create a calming wind-down routine. You might also consider meditation or breathing exercises before bed. If the nightmares are rooted in trauma, therapy like CBT-I or imagery rehearsal therapy may help.

Is there any medication for nightmares?

Yes, certain medications can help reduce the frequency and intensity of nightmares, especially in cases linked to PTSD or anxiety. Prazosin, for example, is sometimes prescribed off-label for this purpose. Always talk to your doctor before considering medication for sleep-related issues.

Why do I keep waking up after bad dreams?

Nightmares activate the body’s stress response, which can jolt you out of sleep with increased heart rate and adrenaline. If you wake up after a bad dream, grounding exercises like deep breathing or progressive muscle relaxation can help you calm down and return to sleep more easily.

I had a nightmare and now I'm scared to sleep. What should I do?

Fear of sleep after a nightmare is common. Your body may still be on alert, so lying down can feel unsafe.

Start by slowing your breathing and naming a few things you can see in the room. A soft light is fine if it helps you feel safe. You don’t have to fall asleep right away. Sitting up with a book in low light until you feel calm is okay, and dropping the pressure to sleep often eases the fear.

If the fear comes back the next night, keep your bedtime routine the same and avoid replaying the dream in your head. Writing it down earlier in the day can help. Fear that keeps returning, or frequent nightmares, is worth raising with a doctor or mental health professional.

What’s the difference between bad dreams and night terrors?

Bad dreams (nightmares) happen during REM sleep and usually involve vivid, disturbing scenarios that you remember upon waking. Night terrors occur during non-REM sleep and involve sudden arousals, often with screaming or thrashing, but the person usually doesn’t remember them. Night terrors are more common in children but can affect adults too.

AI is stealing students’ ability to think critically–Journalism 101 may be an antidote

📅 Oct 23, 2026  |  Category: Technology  |  Read Source →

The risks of using generative Artificial Intelligence in education outweigh the benefits. That’s the warning in a seminal report from the Brookings Institution’s Center for Universal Education. 

After a year of study, focus groups and interviews with 500 students, parents and educators, Brookings warns that overreliance on AI could stunt skills like critical thinking before students have had the chance to learn them. Studies already show there’s cause for concern. 

It doesn’t have to be this way. Brookings’ researchers note that AI technology can enhance student learning instead of supplanting it — if young people learn to think for themselves first.  

Journalism class is the perfect place for students to learn AI-proof critical thinking skills.  

I teach journalism at Jupiter Middle School in Palm Beach County. In our classroom-turned-newsroom, students analyze information, verify facts and consider different viewpoints for every story they publish. They wrestle with ethical dilemmas, use their own judgement and write their own copy.  

They rely on their own brain power instead of offloading difficult tasks to a chatbot. In the process, they’re not only learning how to think for themselves but also getting an education in what it means to be an informed and engaged member of their community.   

On deadline day, our classroom is buzzing. Kids are running around asking for a photo they can’t find, checking out a press pass so they can speak to a source and get a better quote, and our layout editor is frantically trying to ensure that the cropping of a photo doesn’t distort the image — all things journalists regularly do.  

But well before publishing a word, students start with learning basic news literacy skills.  

Sixth graders learn to evaluate the credibility of sources, understanding why a TikTok post may not be the most reliable place to gather facts. They learn to recognize bias by looking for emotionally charged words, noting whose viewpoints might be missing from a piece and comparing how different sources frame the same facts. They come to understand why accuracy matters — because a journalist’s credibility is all they have. It’s all critical thinking in action.  

They continue building these skills in seventh and eighth grade, when they work in a real newsroom where facts, verification and ethical decisions are integral to every publication.  

These are responsibilities that require human discretion and knowledge. They shouldn’t be trusted completely to AI. They are also the kinds of skills that bring us closer as a community.  

Students see firsthand that credible information doesn’t happen by accident; it requires responsibility and care. When tweens and teens are trusted to produce real journalism, they begin to understand their role in contributing thoughtfully to their community. 

Today, many of us are living in separate, screen-based realities. We spend hours scrolling social feeds or chatting with bots instead of interacting in real life. Our filter bubbles can prevent us from any exposure to ways of thinking and living that are different from our own.  

In journalism class, I’m always asking my students to debate complicated issues and consider other perspectives. Journalism ethics call on reporters to be fair and nuanced, which is only possible when you purposely seek out all sides of a story. 

Last year, one of my students wanted to investigate the effectiveness of practicing lockdown drills, but she was genuinely nervous about writing the story. She knew that school safety is an especially sensitive subject — Marjory Stoneman Douglas High School in Parkland, where 17 people died in a 2018 mass shooting, is just an hour’s drive from our school. She worried that questioning a practice designed to protect students might be perceived as criticizing it. 

I reminded her that the job of a journalist isn’t to decide whether the drills are effective. Her job was to ask a legitimate question and then do the work necessary to answer it responsibly. She researched the purpose and effectiveness of safety drills, sought out credible information like case studies and statistics and considered perspectives beyond her own experience as a student. 

I want my students to be informed, engaged citizens when they leave this class. I want them to use their journalism skills to research issues, seek out nuance and make informed decisions. I want them to think for themselves about what’s important to them and why.   

AI is moving quickly into our lives and into our classrooms. Our kids need to stay ahead of it. We need to invest our educational resources to ensure every student learns to think critically.  

News literacy education and journalism class are the perfect places to teach these skills. The goal isn’t to raise a generation of journalists. It’s to equip Gen Alpha with the ability to ask the right questions and listen thoughtfully to the answers — skills that make us human and shouldn’t be handed over to bots.

Take 12 days out of Robinhood Chain's first quarter, and the "3-month-old L2 beat Ethereum" headline turns around.

For the other 80 days, Robinhood Chain earned about $166,000 a day in network fees. Ethereum averaged about $446,000.

ARK Invest's numbers are accurate. Robinhood Chain did generate about $51 million in Q3 against Ethereum's roughly $41 million. But the coverage repeated the comparison without checking how the $51 million was made or who ends up with it. Going back to the underlying data, and the comparison holds up much less well than the headline suggests.

The Headline: A 3-Month-Old Chain Beats Ethereum

ARK's DeFi Quarterly for Q3 2026 charts "Network Real Economic Value by Blockchain". In it, Robinhood Chain logged about $51 million in its first quarter, while Ethereum logged about $41 million, down roughly 35% from the previous quarter.

The comparison spread quickly. A chain that launched on July 1 beating the network that secures most of DeFi made an easy headline. ARK's wider data has more context: total network value across the chains it tracks rose about 24% to roughly $349 million, the first quarterly increase in five quarters, though still about 47% below a year earlier. Robinhood Chain processed about $65 billion in DEX volume, fourth in ARK's dataset, and hosted about $13.7 billion in tokenized equities.

What ARK Is Actually Measuring

ARK's DeFi Quarterly glossary defines Real Economic Value (REV) as "the total value a network generates consisting of both in-protocol transaction fees and out-of-protocol tips," using data from Blockworks Research.

In other words, both figures measure the same thing: gross fees users paid to use the chain. Robinhood Chain's $51 million matches the $51.0 million in user network fees reported in growthepie's Q3 review of the chain. It's not app revenue. growthepie puts the revenue of apps on Robinhood Chain separately, at $591.4 million.

So ARK didn't mix up its metrics. The trouble is that the same metric means very different things on these two chains. The Q3 number doesn't show that.

Twelve Days Produced Three-Quarters of the Fees

growthepie's report has the detail the headline leaves out. A 12-day surge, from August 30 to September 10, pushed median transaction costs to 31 times their pre-surge average. That surge produced 74% of the quarter's fees. growthepie names Relay as the largest tracked fee payer.

Here's what that means in dollars:

  • During the surge (12 days): about $37.7 million, or roughly $3.1 million a day
  • The rest of the quarter (80 days): about $13.3 million, or roughly $166,000 a day
  • Ethereum, over the full 92 days: about $41 million, or roughly $446,000 a day

Outside the surge, Robinhood Chain earned about 37% of Ethereum's daily rate. At that pace, a full quarter would come to about $15 million, well under Ethereum's $41 million. The "out-earned Ethereum" result depends almost entirely on 12 days when fees jumped to 31 times normal.

That doesn't make the surge fake. Users paid those fees. But the surge came from congestion and higher prices, not steady growth. Across the quarter's 793.7 million transactions, users paid about 6.4 cents per transaction on average. Median costs that briefly rose to 31 times normal aren't a pricing model an exchange-backed chain will want to repeat.

Same Label, Different Economics

Even with the same metric, the two figures go to very different places.

On Ethereum, most of the $41 million is the base fee, which is burned. That reduces ETH supply and benefits every holder. The rest goes as priority fees and tips to thousands of independent validators. Ethereum's REV is close to a public measure of what the network's users pay.

On Robinhood Chain, an Arbitrum Orbit rollup, fees go to the chain's sequencer, which Robinhood operates. In practice, the $51 million is a company's gross receipts. Some of it goes back to Ethereum to pay for posting data and settling transactions there, and the rest is Robinhood's margin. As coverage of the report noted, how much reaches Robinhood's income statement is still unclear. The company's earnings report on October 27 may answer that.

So on one side, you have fees paid to a decentralized base layer, mostly destroyed. On the other, you have gross receipts for one company, before costs. Both count as "network value," but they aren't the same kind of income.

What the Comparison Leaves Out

Three more things make the head-to-head weaker:

  • Ethereum's low fees are by design. Ethereum has spent two years making its base layer cheaper and moving activity to rollups. A lower fee total partly reflects that strategy.
  • Some of Robinhood's fees go to Ethereum. As a rollup, Robinhood Chain pays Ethereum for data availability and settlement. That cost is included in Robinhood's $51 million. Whether ARK also counts Ethereum's share of it or not, either way, Robinhood's figure includes a payment to the chain it's being compared with.
  • One quarter is a short window. Robinhood Chain's numbers come from its launch quarter, and much of the activity was concentrated in a short period. Stablecoin supply on the chain did grow from $102.3 million to $1.07 billion, passing $1 billion on September 7, which is a more durable sign of growth than a fee spike.

A Fairer Way to Read the Numbers

The accurate version of the headline is less dramatic: in its first quarter, Robinhood Chain charged its users more in total than Ethereum's base layer did. About three-quarters of that came from a 12-day congestion spike, and the money went to Robinhood's sequencer, not to a decentralized validator set.

That's still a strong debut. Robinhood Chain's stablecoin growth, $13.7 billion in tokenized equities and nearly 800 million transactions are all real. But "beat Ethereum" tells you more about one busy fortnight in early September than about which chain has the stronger business. Q4 will be the real test: without a surge, can Robinhood Chain's fees come close to Ethereum's on an ordinary day?

New Research Strengthens the Case for Emotional Dysregulation in ADHD Criteria

📅 Oct 23, 2026  |  Category: World  |  Read Source →

When the Diagnostic and Statistical Manual of Mental Disorders (DSM-5) was updated in 2022, officials believed that research was lacking to expand ADHD’s definition to include the common and extremely impairing symptom of emotional dysregulation. Consequently, the overwhelming and uncontrollable emotions reported by many patients remain largely unrecognized as ADHD manifestations.

Now research appears to be catching up to patient reports.

A new landmark study has revealed three ADHD subtypes that reflect neurobiological differences: predominantly inattentive; predominantly hyperactive/impulsive; and the new severe-combined, which is marked by emotional dysregulation.1

Using neuroimaging and computational modeling to map the pathways of ADHD, researchers found that the severe-combined type had 45 areas of brain abnormality tied to emotion and control compared with 26 each for the two other types. The study, which analyzed 1,154 brain scans of children and adolescents with ADHD, was published recently in JAMA Psychiatry.

New Presentation, New Treatment?

The findings are “an example of recent insights emerging from neuroimaging that may impact clinical care, which has been an elusive goal,” says F. Xavier Castellanos, M.D., professor emeritus of child and adolescent psychiatry at New York University’s Grossman School of Medicine. He was part of the working group that contributed to the DSM-5.

[Get This Free Download: Emotional Regulation & Anger Management Scripts]

“Still, it’s too early to assume that their intriguing results are real in the sense of replicating repeatedly in independent datasets, particularly by investigators who are not allied or collaborating with the original research team,” says Castellanos. He, like the study authors, calls for prospective studies to validate their biotypes and determine whether they may influence treatment.

Findings that reveal a new severe-combined subtype may come as no surprise to the thousands of parents of children with ADHD, and adults with the condition, who have named emotional dysregulation as the most impairing feature of ADHD in ADDitude surveys.

But, as David Anderson, Ph.D., senior psychologist at the ADHD and Behavior Disorders Center at the Child Mind Institute, points out, parents’ anecdotal feedback precedes scientific validation.

“Finding evidence of a subtype in the brain leaves open questions about the balance of nature versus nurture. Is there a biological basis for subtypes and is it reliable across the span of development?” Anderson asks. “Emotion dysregulation can be biological for kids who are more prone to emotional behavior from an early age, while some are frustrated with the world due to negative feedback they’ve gotten since kindergarten, so it’s environmental. There are multiple pathways to come to this.”

[Read: The Key to ADHD Emotional Regulation? Cultivating Gratitude, Pride & Compassion]

If the study’s findings are replicated, Castellanos says, it would become a new presentation in a future version of the DSM. “I served on the DSM-5 committee, and we were explicitly reminded that the DSM follows the field; it does not lead it. It’s only when the scientific evidence is strongly supportive that DSM changes are allowed. Otherwise, it’s too disruptive.”

Stephen V. Faraone, Ph.D., distinguished professor at SUNY Upstate Medical University, said he believes that emotional dysregulation was not included in the DSM-5 because it might have made differential diagnosis with anxiety and mood disorders more difficult, especially in primary care. He also said he was skeptical that ADHD can be divided into biological subtypes, adding that underlying ADHD brain mechanisms exist along a spectrum and do not fall neatly into separate categories.

The study’s researchers said the findings may eventually create a path toward developing personalized therapeutic strategies.
