Security Update on PHP2Shell: Impact for Docker Customers

📅 Oct 22, 2026  |  Category: Other  |  Read Source →

Summary

On Tuesday, October 20, 2026, Docker began tracking two critical vulnerabilities in PHP, CVE-2026-109618 and CVE-2026-109619, commonly known as PHP2Shell. The vulnerabilities allow attackers to execute code remotely in PHP core, and they affect PHP packages going back to version 5.4: the supported versions 8.2 through 8.5, and the end-of-life versions 5.x, 7.x, 8.0, and 8.1.

To address these vulnerabilities, PHP released 8.5.12, 8.4.27, 8.3.36, and 8.2.35, and advised anyone running PHP to update to the latest version immediately.

Although this is a vulnerability in PHP itself, not in Docker’s systems, it nonetheless affects Docker users who build on PHP images and packages. In response, we have updated the Docker Hardened Images and Docker Official Images on Docker Hub, and advise customers to immediately update.

What Happened

Along with other package repositories and secure package providers, Docker has been made aware of and is tracking two recently discovered critical vulnerabilities in PHP packages distributed since version 5.4. The two critical vulnerabilities, now commonly referred to as “PHP2Shell,” are identified and tracked as CVE-2026-109618 and CVE-2026-109619. (The PHP Foundation has published a detailed report on the discovery that we recommend reading for full context.)

In short: these vulnerabilities could allow remote code execution in PHP core by malicious actors. Both are flaws in how PHP manages request memory. In CVE-2026-109618, when PHP runs out of memory mid-request and aborts, some code paths leave memory uninitialized, and PHP’s cleanup step then reads it. In CVE-2026-109619, PHP’s internal state can keep pointing at memory that has already been freed, and a later request then uses that stale state. Attackers have multiple ways to trigger either condition and turn it into remote code execution.

Affected versions include the currently supported versions (8.2 through 8.5), as well as the EOL and unsupported versions 5.x, 7.x, 8.0, and 8.1.

Impact to Anyone Using PHP

Whether you are a Docker user or not, if you are using any of the above affected versions of PHP, you should immediately upgrade to the latest version. That includes PHP 8.2.35, 8.3.36, 8.4.27, or 8.5.12, or a later release in the corresponding branch.

There is no other comprehensive remediation for the affected versions. Updating is the only complete mitigation path.

If for any reason you are unable to complete an immediate update, we strongly recommend taking your system offline until such time that you can initiate mitigation. This the guidance of not only Docker, but of the FBI, and numerous experts throughout the cybersecurity community.

Impact to and Actions for Docker Users

While this vulnerability exists in PHP itself and not directly in Docker’s systems, there is nonetheless potential risk and exposure to Docker customers who run PHP in their applications, including anyone using PHP images or packages from Docker Hub, Docker Official Images, or Docker Hardened Images.

For users of Docker Official Images:
Docker Official Images have already been updated and released to Docker Hub and mirrored to Amazon ECR. Customers using either of these sources should update immediately.

For users of Docker Hardened Images (DHI):
Docker Hardened Images have already been updated and released to Docker Hub. The currently supported versions of PHP were updated as follows:

  • 8.2.34 → 8.2.35
  • 8.3.35 → 8.3.36
  • 8.4.26 → 8.4.27
  • 8.5.11 → 8.5.12

The updates to our images were completed and released within 24-hours of the upstream patches being made available. These images were made available after successfully executing the DHI testing and verification processes.

What’s next

If you have any issues accessing the updated images or migrating to the new versions, please contact Docker Support at app.docker.com/support/contact. As always when it comes to matters of security, we appreciate your diligence.

As Cybersecurity Awareness Month continues, the GitHub Bug Bounty team is excited to spotlight another top-performing security researcher from the GitHub Security Bug Bounty Program: @r31n!

As home to the world’s developers, GitHub is dedicated to the security and reliability of the code behind millions of projects, and our Bug Bounty Program remains a cornerstone of that commitment. Collaboration with external researchers is one of the most effective ways to improve security, and every year, the community helps us identify and fix vulnerabilities that make the platform safer for everyone.

The security research landscape is changing rapidly. AI has lowered the barrier to entry and become a genuine force multiplier. We use it across our own internal security programs, and we welcome researchers who do the same. However, what separates great research has not changed: validation, a working proof of concept, and a clear demonstration of real security impact. The tools do not matter; the quality of the work does. The researchers we spotlight this month exemplify exactly that standard through findings that are verified, reproducible, and demonstrate that a security boundary has been crossed rather than simply theorizing that one exists.

Researchers who consistently work at that level can earn an invitation to our permanent VIP program, which offers higher payouts, faster response times, and early previews of beta products and features. Learn more about how to qualify on our public bounty site.

As we wrap up our Cybersecurity Awareness Month celebration, we interview @r31n, a researcher renowned for their work on GitHub Enterprise Server, where they have repeatedly uncovered high-impact issues. Their reports consistently include working proofs of concept and clear reproduction steps, helping our engineering teams move from triage to remediation more quickly.

How did you get started in security and bug bounty, and what keeps you coming back to GitHub’s program?

I got into bug bounty because I wanted a way to keep developing my security skills outside the environments I work with every day. It exposes me to different products, technologies, and architectures I probably wouldn’t run into otherwise. GitHub is one of those programs I keep coming back to because there’s just so much surface area. It’s large, complex, and constantly changing. New features ship all the time, so it never really feels like a finished target. They also work closely with researchers, the bounty structure is competitive, and the swag is a nice bonus. It’s simply a program I enjoy spending time on.

What are your favorite classes of bugs to research and why?

I don’t really have one favorite bug class. What interests me more are exploit chains, especially cases where a few things that seem relatively harmless on their own come together and create something much more serious. An open redirect is a simple example. By itself, the impact might be limited. But if you find an allowlisted-domain SSRF that follows redirects, suddenly that open redirect can become a useful part of a much bigger chain. That’s probably the part of vulnerability research I enjoy most: finding those connections, looking at two or three separate bugs and realizing they can be combined in a way that wasn’t intended. It takes some technical knowledge, but also quite a bit of creativity.

How do you keep your skills sharp and stay on top of new vulnerability trends?

It’s actually a mix of different things. Security blogs, vulnerability write-ups, conference talks, proof of concepts, research papers, courses. I try to learn from wherever useful work is being shared. But most of it only really sticks once I try it myself. I can read a vulnerability write-up, but working through it myself gives me a much deeper understanding. If I actually reproduce the technique, play around with it, break it, and figure out why it behaves the way it does, that’s when it really stays with me. And later, when I see a similar pattern on a real target, it’s much easier to recognize.

What tools or workflows have been gamechangers for your research? Any lesser-known utilities you’d recommend?

I tend to prefer manual investigation and small, purpose-built scripts over large automated toolchains. If I notice I’m repeating the same task during research, I’ll usually automate that specific part. AI has probably impacted my way of working more than any individual security tool.

Even then, I think mindset matters more than tooling. You can become extremely good with a particular tool and still miss interesting bugs because you’re only looking at the target through the lens that tool gives you. Sometimes relying too heavily on tooling actually narrows the way you think. Tools change. Techniques change. Curiosity and persistence tend to age much better. So, I don’t really have one tool I’d recommend to everyone. The most useful tool is usually the one that helps answer the specific question I’m investigating.

Walk us through your general approach. How do you pick a target area, and how do you go from “interesting feature” to a confirmed finding?

I usually start by mapping out the application and getting a feel for how its different parts fit together. I tend to spend more time on complex functionality, integrations, trust boundaries, and anything that behaves a little differently from the rest. Experience and intuition matter too. Some areas simply look more likely to expose interesting security behavior. From there, I often think in terms of sources and sinks rather than starting with a specific vulnerability class. A source is a point where attacker-controlled data enters the application.

Think of a request parameter, uploaded file, API input, or data coming from another service. A sink can be a security-sensitive operation that consumes this data, for example, a network request, file access, process execution, database query, or authorization decision. The interesting part is tracing the path between the two. I look at how the data is transformed, validated, or passed across trust boundaries, and whether those controls are sufficient before it reaches the sink.

I like this approach because it lets me reason about attack paths without forcing my investigation into a predefined bug class. Sometimes the vulnerability only becomes obvious once you understand how a particular source can influence a security-sensitive operation. I consider a finding confirmed once I understand the attack path, can produce a working PoC, and can explain the impact.

Do you use AI in your research? Where does it genuinely help and where does it fall short?

Yes. Quite a lot, actually, but mostly as an accelerator. I use it for navigating unfamiliar code, finding call sites, tracing data through the codebase, and understanding how a system is structured and how its components interact. I also find it helpful for writing PoC scripts once I’ve identified the vulnerability.

Where it works best is when the question is specific. “Is this application vulnerable?” usually isn’t a very useful prompt. Give it the right context, explain what you already know, and ask a narrow question, and the quality goes up dramatically. There’s a bit of a paradox there. AI becomes more useful as you understand the problem better yourself. And I never treat its conclusions as facts. Hallucinations, false positives, bad assumptions, and confidently wrong answers are all common. Everything should still be manually verified. AI makes my work faster. However, it doesn’t replace understanding the application, developing intuition, or proving that something actually works.

What’s your guidance on using AI responsibly in bug bounty?

Use it to improve your research, not to outsource responsibility for it. If AI tells you it found a vulnerability, that doesn’t mean you found a real vulnerability. You still need to reproduce it yourself. You should understand exactly what’s happening, which security boundary or control is being violated, and what the real impact is. Ideally, you should understand the issue well enough that you could write the report without AI at all. Build a clear PoC. Make sure the security team can follow it. Know why every step matters.

AI has lowered the barrier to doing security research, which is great in a lot of ways. But you can also see the downside in the number of unverified reports teams now have to deal with. AI should make research better. Not just make more reports.

As the industry ships more AI-powered features, does testing them require a different mindset than traditional web bugs?

Yes. Conventional vulnerabilities still matter, but attackers may also be able to influence a probabilistic decision-making component through the data, instructions, or context it receives. But getting a model to say or do something unexpected isn’t necessarily the interesting part. The more important question is what that influence allows an attacker to achieve. Can they access something they should not or cause the system to act with privileges the attacker does not have? That’s why I don’t think model-level guardrails should ever be treated as the only or primary security boundary. You still need deterministic controls around the model. This includes proper authorization, least-privilege access, isolation, and validation. The surrounding systems matter just as much as the model itself. And traditional application security doesn’t disappear just because AI is involved. Model output should still be treated as untrusted input. If that output ends up in a browser, database query, shell command, web request, or another downstream system without the right controls, you can still end up with very familiar vulnerabilities: XSS, SQL injection, command injection, SSRF, and so on. I think the model is new. A lot of the dangerous sinks aren’t.

What’s one thing you wish you’d known when you first started?

Learn systems, not checklists. When I started, I was tempted to collect huge lists of techniques, payloads, tools, and bypasses and then work through them one by one. Those lists can be useful.

I still use them. But understanding how a system works has been far more valuable. Its internal logic. The data flows. Trust relationships. Assumptions. Why one component is allowed to talk to another. Why a particular restriction exists in the first place. I also learned not to assume something is secure because it looks secure, or because plenty of researchers have already tested it.

A lot of interesting research begins with: “Why does this work this way?” rather than “Which payload should I try next?” There’s some luck involved too. Sometimes you spend days following something that goes absolutely nowhere. Then you notice one tiny detail almost by accident and it turns into a high-impact finding. You can’t control that part. You can control whether you keep questioning things long enough to notice it.

What advice or resources would you recommend to researchers trying to land their first valid report?

Get comfortable with the fundamentals, then pick one program and one target and stick with them for a while. Constantly jumping between targets makes it difficult to build a real mental model of any of them. Use the application. Explore weird flows. Test different roles and permission levels. Read the documentation. Watch the requests and responses. Look at the APIs. Labs, courses, public write-ups, disclosed bug bounty reports, and intentionally vulnerable applications are all useful too. They teach you where bugs tend to hide and, over time, help build the intuition to recognize similar situations elsewhere.

One mistake I see a lot is relying on tools too early. Another is giving up because the obvious tests didn’t find anything. Tools help. They don’t build the mental model for you. And when you finally do find something, spend the extra time validating it properly. Create a working PoC. Make reproduction easy for the security team. Understanding one target deeply will usually get you further than trying to find a bug as quickly as possible.

What do you enjoy doing when you aren’t hacking?

Endurance sports, mainly road cycling, especially in the mountains. I enjoy the physical challenge of a long climb and pushing myself over longer distances. It’s also a great way to get away from screens for a while and spend some time outside. There’s actually something about climbing that feels pretty similar to vulnerability research. You can put in a lot of effort without seeing much progress. Sometimes you have no idea whether what you’re doing is going to lead anywhere. You just keep going. And every now and then, it pays off.

Any social media profiles you’d like to share with our readers?

You can find me on HackerOne.

Thank you, @r31n, for participating in GitHub’s bug bounty researcher spotlight! Each submission to our bug bounty program is a chance to make GitHub, our products, and our customers more secure, and we continue to welcome and appreciate collaboration with the security research community. So, if this inspired you to go hunting for bugs, feel free to report your findings through HackerOne.

Would-be homebuyers are pulling back as mortgage rates remain in the mid-7% range.

What to know about the U.S. housing market for the four weeks ending October 18: 

  • Pending home sales fell. They declined 1.9% from a week earlier to the lowest level in records dating back to 2021. Weekly average mortgage rates are holding steady at 7.4%, pricing out many house hunters. For the second week in a row, pending sales declined in all 50 of the most populous U.S. metro areas. 
  • The typical monthly payment jumped to the the second-highest level on record. The median housing payment for a homebuyer is $2,796, as mortgage rates stay high. But the median home-sale price rose just 0.2% year over year, following two weeks of 0.1% increases, a sign that prices are losing steam. 
  • Fresh supply is falling. New listings declined 1.4% from a week earlier to the lowest level since July as homeowners take note of slow homebuying demand. 
  • Total inventory is still growing–but barely. The total number of homes for sale inched up 0.1% week over week; even though new listings are falling, the total number of homes for sale is holding up because buyers aren’t depleting the pool very quickly. There are hundreds of thousands more home sellers than buyers throughout the country, giving buyers the most negotiating power they’ve had in over a decade.

ActiveState Partners with Docker to Secure the Open Source in Enterprise Containers

📅 Oct 22, 2026  |  Category: Technology  |  Read Source →

Even security teams that have invested in a hardened base image often can’t say what’s running on top of it. In a recent survey of 250 North American DevSecOps leaders, 91% named visibility into container components as their single biggest blind spot. Not the base image, but everything layered onto it. And 90% said their teams still run lightly modified public images with little to no hardening. 

That gap is getting harder to ignore. AI coding assistants are adding dependencies faster than teams can review them. Vulnerability databases can no longer keep pace with the volume of submissions. New regulatory requirements, including the EU Cyber Resilience Act, are also increasing expectations around vulnerability handling, remediation, and software supply chain transparency. 

Docker Hardened Images meet ActiveState’s Curated Catalog

Docker, Inc. and ActiveState today announced a reselling partnership that brings Docker Hardened Images (DHI) together with ActiveState’s curated open source packages, giving enterprises a more consistent way to secure both the container base and the software dependencies layered on top.

DHI provides secure-by-default, minimal container images, with 4,000+ images built from source, near-zero CVEs, signed SBOMs, and SLSA Build Level 3 provenance. The catalog is free and open source under Apache 2.0, with production tiers backed by a 7-day SLA for critical and high-severity CVEs. 

ActiveState extends that trusted foundation to the open source dependencies developers add on top. Its curated components span more than a dozen language ecosystems, including Python, JavaScript, Java, Perl, Tcl, and Ruby. Components are built from source, continuously maintained and remediated against contractual SLAs, and delivered through the package managers, pipelines, IDEs, and AI coding tools development teams already use. 

Trust across the software stack

  • A more consistent approach to trusted open source: Pair a hardened container base with curated open source dependencies, reducing the need to source and manage each layer separately
  • Verifiable provenance across the stack: With both Docker and ActiveState building from source to SLSA Build Level 3 standards, teams get a more consistent evidence trail across the software supply chain
  • Fewer vulnerabilities, without slowing teams down : DHI delivers near-zero CVEs, 95% smaller attack surface, 7-day SLA on critical/high CVEs. ActiveState provides 95% fewer CVEs and 90% faster remediation than community open source, backed by a 5-day SLA on critical vulnerabilities.

How to deal with anxious-ambivalent attachment in a relationship

📅 Oct 22, 2026  |  Category: Health  |  Read Source →

Clinically reviewed by Dr. Chris Mosunic, PhD, RD, MBA

Wondering if anxious-ambivalent attachment is affecting your relationships? Learn the signs, causes, and 10 tips to support yourself or a partner with this attachment style.

Have you ever texted your partner only to spiral into oblivion waiting for them to respond? You wonder if they’re upset with you, if you did something wrong, or if they’re quietly pulling away. When their response finally comes through, you exhale the biggest sigh of relief. And then you start second-guessing why you were so worried in the first place. 

If this sounds familiar, you may be dabbling in the world of ambivalent attachment, which is one of many attachment styles formed in adolescence and carried into adulthood.

Ambivalent attachment is a relationship pattern where you want to feel close to your partner but can’t always get there. It can show up as craving reassurance but doubting it, swinging between feeling connected to your partner and fearing they’ll leave, or analyzing small interactions for a hidden meaning that often isn’t there. While it may feel overwhelming, this attachment style isn’t a flaw in your personality, but rather a pattern shaped by early experiences in your life.

Let’s unpack what ambivalent attachment means, how to spot the signs in adulthood, and what to do if you (or your partner) lean toward this attachment style. Plus, we’ll dive into how to create steadier, more supportive relationships that feel good for all involved.

 

What is an anxious-ambivalent attachment style?

Anxious-ambivalent attachment—also called ambivalent attachment—is a relationship pattern where you crave reassurance yet struggle to feel settled once it’s given. It’s like wanting to lean on someone but worrying they might step away just as you do.

In adult relationships, ambivalent attachment may show up as feeling unsure about your partner’s commitment to you, cycling between connection and doubt, or getting caught in emotional highs and lows depending on how available your partner feels to you. 

While it can feel overwhelming, this isn’t a flaw. It’s a protective strategy learned early in life that can be reshaped over time.

 

What causes an ambivalent attachment style?

Ambivalent attachment often develops in childhood when caregiving is inconsistent. Basically, sometimes you were nurtured, and sometimes you weren’t. This unpredictability creates uncertainty in children, as they learn that comfort may arrive (but not reliably), so they cling tightly when it does appear. Over time, this wires the nervous system to stay on high alert for signs of loss or disconnection.

While it may seem easy to blame the caregivers involved, that’s not always the best answer or solution. Many people provide inconsistent care because of stress, lack of support, or their own attachment struggles. The good news is that even if this style formed early, it can shift in adulthood through consistent experiences of safety and connection.

 

6 signs of an anxious-ambivalent attachment style in adulthood

Ambivalent attachment doesn’t always look dramatic from the outside. It often shows up in subtle, everyday ways that leave both partners feeling drained or confused. While everyone feels insecure at times, people with an ambivalent attachment style experience these patterns more intensely and more often.

1. Constant need for reassurance: You might ask for confirmation of your partner’s love or commitment regularly through words, texts, or gestures. The tricky part for people with an ambivalent attachment style is that reassurance often doesn’t stick. Even after hearing “I love you,” doubt can creep back quickly, fueling the cycle for reassurance again.

2. Fear of abandonment: Small shifts in a partner’s behavior—like if they take longer than usual to reply to a message or are quieter than usual—can trigger unnecessary worry. The fear isn’t just about being left by your partner, it’s about being forgotten or no longer valued. And for someone with this attachment style, those fears can be dire.

3. Hyper-attunement to signals: People with ambivalent attachment often read between the lines of every interaction, scanning tone, body language, or text punctuation for hidden meaning. A short text that simply says, “K,” might feel like rejection rather than just brevity.

4. Emotional highs and lows: Relationships can feel like a rollercoaster. You may feel ecstatic when things feel close and connected, then anxious when any distance appears. The intensity of these swings can feel overwhelming for both partners.

5. Difficulty trusting stability: Even when the relationship is going well, there’s a lingering sense that it could change at any moment. This makes it hard to relax into intimacy, because safety doesn’t feel fully reliable.

6. Feeling “too much” or “not enough”: Self-doubt often runs in the background, accompanied by persistent worrying that your needs are excessive or fearing that you’re somehow lacking. This inner tug-of-war can make it difficult to feel secure in how you show up in a relationship.

 

How to deal with anxious-ambivalent attachment in yourself or a partner

Working with ambivalent attachment is about finding steadier ground, both within yourself and your relationships. These strategies combine self-regulation, clearer communication, and practical agreements that build trust over time.

If you relate to ambivalent attachment

1. Recognize and name the pattern: The first step is simply noticing when old fears are coming up. Take time to put a name to the feeling, and remind yourself that it’s a learned response and not proof that something is wrong with you or your relationship. Taking a beat to give your feelings a name gives you the chance to pause before you react impulsively.

2. Soothe your body before your thoughts: Ambivalent attachment often activates the nervous system, which can make worries feel louder than they are. Simple grounding tools, such as intentional breathing, a mindful walk, or even running cold water over your wrists (which may help calm your nervous system) can bring your body back to baseline. Once you’re calmer, you’ll have more perspective on what’s really happening.

3. Ask directly instead of protesting: Protest behaviors (testing someone, withdrawing your affection, or sending a string of texts from the top of your mind) can backfire and push your partner away instead of bringing them closer. Practice naming your needs clearly instead. Try saying something like, “I’m feeling anxious right now and could use reassurance that we’re okay.” It might feel vulnerable to be so honest and open, but being direct usually leads to better connection.

4. Build a personal reassurance toolkit: Instead of depending only on your partner for reassurance, create a set of resources you can turn to yourself. This might include rereading kind messages, journaling, doing grounding exercises, or calling a supportive friend. Having options beyond your partner reduces the sense of desperation when anxiety spikes.

5. Practice small steps toward trust: Shifting attachment styles takes time, but small experiments help. Try waiting a little longer than you typically would before sending a check-in text, and see how that feels. You can also remind yourself of past experiences where closeness stood the test of time or survived a disagreement. Each successful moment builds evidence that security is possible, even if your old fears insist otherwise.

If your partner relates to ambivalent attachment

6. Offer steady reassurance with boundaries: Consistency may help calm anxiety. Simple habits like a morning check-in or saying when you’ll call back create predictability. But it’s also important to pair reassurance with realistic boundaries. You might say, “I can’t text during work, but I’ll check in at lunch.”

7. Respond to the need, not just the words: Underneath protests or big reactions is usually a fear of being abandoned. Instead of focusing only on the tone or delivery of something your partner says, try reflecting the underlying need. You can say, “I hear that you’re worried I’m pulling away, but I want you to know I’m here.” This validation often matters more than a perfect solution.

8. Set clear repair practices: When tensions rise, agree in advance on how to pause and return to the conversation when you’re level-headed. Try saying, “If one of us feels overwhelmed, we’ll take a 20-minute break and come back at an agreed time.” Returning as promised helps rebuild trust, strengthens your relationship, and makes conflicts feel less threatening.

Practices for both of you together

Ambivalent attachment FAQs

What causes ambivalent attachment?

Ambivalent attachment usually begins in early childhood. When a caregiver is sometimes warm and attentive but other times distracted, stressed, or unavailable, a child learns that love is unpredictable. This inconsistency creates anxiety about whether comfort will be there when it’s needed most. 

Over time, the child develops strategies to cling tightly to connection, like seeking closeness while bracing for it to disappear. It’s not always about neglect. Often, caregivers themselves are overwhelmed or carrying their own attachment wounds. But the result is the same, and it’s that love is both essential and unreliable.

How do I know if I have ambivalent attachment?

You may notice repeating patterns in your relationships, like craving reassurance but rarely feeling settled when you receive it. Small shifts in your partner’s tone, attention, or texting habits may trigger outsized worry about abandonment. 

Overthinking, analyzing, or swinging between feeling deeply connected and then uncertain are also common. If these patterns show up across multiple relationships, that can be a strong sign of ambivalent attachment.

Can an ambivalent attachment style change over time?

Attachment styles can change. While your early experiences lay the foundation, your attachment style can shift as you build new experiences of safety and stability. Supportive relationships, therapy, and personal work on self-regulation all help strengthen secure attachment. 

The process is gradual and often happens through repeated moments of repair and reassurance. Over time, these experiences retrain your nervous system to trust that closeness can last.

What’s the difference between ambivalent and avoidant attachment?

Both ambivalent and avoidant attachment come from early inconsistencies in caregiving, but they lead to opposite coping strategies. People with ambivalent attachment often lean in, seeking closeness, reassurance, and connection. Sometimes, these manifest in ways that feel intense or overwhelming to their partner. 

People with avoidant attachment tend to lean out. They value independence, minimize their needs, and withdraw when relationships feel too vulnerable. Ambivalent attachment is marked by fear of abandonment, while avoidant attachment is marked by discomfort with intimacy.

Can therapy help with ambivalent attachment?

Yes, therapy can be effective. Working with an attachment-focused therapist gives you a consistent relationship where trust and stability are practiced week after week. Different forms of therapy like Emotionally Focused Therapy (EFT), schema therapy, and cognitive-behavioral therapy can help you identify old patterns, calm the nervous system, and create new relational habits. 

Over time, the therapy relationship itself often serves as a secure base, making it easier to bring those new ways of relating into your everyday life.

How can I deal with an ambivalently attached partner?

Patience and predictability are key. Your partner may need more reassurance than you thought, so offering it consistently and directly can ease their anxiety. For example, sending a quick “thinking of you” text before a long meeting or confirming plans in advance can make a big difference. 

At the same time, it’s important to set boundaries around what you can realistically give. A helpful approach is to offer what you can with warmth, and state what you can’t with clarity. That way, your partner feels cared for without you becoming overextended.

Has Substitution Culture Gone Too Far?

📅 Oct 22, 2026  |  Category: Food  |  Read Source →

This excerpt was originally published in Pre Shift, our newsletter for the hospitality industry. Subscribe for more first-person accounts, advice, and interviews.

When Chanita Chayaluk decided to open her restaurant and wine bar Taan, she hoped “to showcase Thai food in Chicago in a different light,” she says. “The first [wave of] immigration of Thai people in Chicago was in the 1970s, and a lot of [Thai] food here still feels like it’s from that time.” In September, she opened with a menu including miang, a Northern Thai dish made with fermented tea leaves, and a whole, deep-fried fish in a fish-sauce caramel. 

Another quirk of operating in Chicago? “We’re still pretty ‘Midwest nice,’” says Chayaluk. “We try to overaccommodate and appease the masses.” In the early days of service, guests made frequent requests for substitutions or accommodations due to preferences and dietary restrictions. “It would slow down service and speed, and that was not just affecting us, but the guest experience in many ways,” she says. With a small kitchen and staff, it was hard to keep up. “It just felt like we were Chipotle.” When a guest asked for green curry mussels “but without the mussels,” it was a turning point. 

Chayaluk implemented a limited substitution policy at Taan, stating on Instagram that ingredients like fish sauce and shrimp paste are “the fabric that defines our cuisine,” and therefore, could not be removed from any dishes that include it. 

A decade or so ago, substitution culture was generally frowned upon and derided. Recently, though, some restaurants report it bubbling back up—and in full force. There’s a swirl of factors that got us here: Lunch slop bowl spots primed customers to expect a detailed level of customization with their orders. Unreasonable Hospitality pushed an intensified “customer is always right” mentality. And influencers entering the food-review space have made criticism of anything—including a restaurant choosing not to honor certain dietary preferences—ripe for an immediate, viral takedown. Couple all of that with the fact that it is hard to keep a restaurant afloat these days, and you’ve got several operators giving in, whether to specific requests, or to altering their menus altogether (see also: the great de-spicification of menus.)

At the same time, restaurants like Taan and New York’s Ha’s Snack Bar—which proudly announces in its Instagram bio that everything contains fish sauce—are standing their ground.

For Lom Wong in Phoenix, Arizona, substitution and modification requests have ramped up after receiving national attention. Chef Yotaka “Sunny” Martin was recognized by the James Beard Awards last year, and the restaurant was named a Michelin Bib Gourmand in August. “[After the award,] we had more guests than we were used to picking things apart. They were asking us to modify dishes or not understanding our service style and why we weren’t coursing things in a European fashion,” says chef and co-owner Alex Martin. “[There is a] European distinction of what an award-winning restaurant looks like, so people equated that recognition with a white-tablecloth restaurant. We were just like, ‘Well, that’s not who we’ve ever been, and it’s never what our restaurant will ever be.’”

Like Taan, Lom Wong took to social media to set expectations, including that the restaurant would not “make substitutions simply to make a dish more familiar,” and that certain dishes might differ from Western expectations of them; beef might have gristle, fishes will be whole, and both choices are fully intentional. “Sunny is our guiding light of cultural context,” says Martin. “[She advises, considering if] changing something about a dish compromises the integrity of the dish.” For example, the mango salad can be ordered with the shrimp on the side, but the restaurant won’t remove beef or shrimp paste from dishes that necessitate them. 

Chayaluk takes a similar approach at Taan; there is always a vegan, gluten-free option (currently a fried rice) that she describes as a “catchall” for those who can’t have other items on the menu. “We make sure that that dish is also really, really good and substantial; it’s not just an appetizer,” she says. “It’s not an afterthought.” 

Staff at both restaurants are encouraged to uphold the boundaries, which both Chayaluk and Martin say are as much in place for protecting their staff’s peace as they are for ensuring quality control for guests. While there has been some backlash, the expectation-setting at the start of the meal (and before, thanks to the social media posts) has for the most part been taken well. “The way we explain [our policy] to guests is kindly saying we respect your preferences, but they’re your preferences,” says Martin, “and steering them toward dishes on the menu that might already align with those.”

I run an edtech platform I hope you barely use

📅 Oct 22, 2026  |  Category: Technology  |  Read Source →

After spending a full week with just pencil, paper, and a willingness to think deeply, students opened up their laptops. Throughout the week, they defined words like “incarceration” and “reparations.” They learned the historical context of World War II and why the U.S. government forced thousands of Japanese Americans to leave their homes for remote relocation centers. They analyzed primary sources. A lot of primary sources. From government documents, newspaper clippings, and personal letters to photographs and propaganda posters. Their papers were marked up with annotations as the classroom filled with conversations around humanity, justice, and understanding.

By the time the unnatural blue light of the computer screen hit the students’ eyes, they had researched, analyzed, and prepared a paper about the impact of incarceration on Japanese Americans during World War II. They did all of this without technology. This begs the question: With such a rich week of learning, why bother pulling out laptops at the end? 

Simply, because synthesizing and sharing learning matters. When we don’t confine learning to one classroom but share it across a department or district, we enable systemic change. Technology can facilitate this. A narrow use of technology, one that cements student learning rather than facilitates it, is key for cultivating a student-centered education system.

In the case of the above example, when students submitted their essay on our online platform, they received instant feedback thanks to AI-informed grading. Their teacher can now use this feedback and the resulting data to identify trends in student thinking and writing. This provides essential information to drive student learning forward. 

Meanwhile, when other classrooms go through the same process, whole departments become more collaborative. Using the data, teachers can set goals around students contextualizing information, citing textual evidence, and defending arguments. A school’s learning culture shifts because technology enables immediate and actionable feedback for students and clear insights for teachers. 

But here is a point that must be stressed: the technology hardly needs to be used to get these results. The technology is there to record the data from student thinking, not to facilitate the thinking or make it ‘fun’. 

We believe that leveraging technology in this very specific way—to provide instant feedback and synthesize complex data—can open the door to an education experience that better empowers students. Its use is minimal but strategic, enabling learning experiences that make us more human. In fact, the technology incentivizes the user to stay on it as little as possible. It’s an affront to the algorithm. It’s boring.  

We are amidst a clear shift happening in education. For the past decade-plus, schools have been adopting education technology wholesale in our K-12 system. Introducing technology in classrooms was a hopeful salve to the rapidly changing culture our students were growing up in. We hoped that more technology would make us more relevant to digital natives and increase their engagement. But the research is coming to light, and this wasn’t the salve tech optimists hoped it would be. As teacher-turned-neuroscientist Dr. Jared Cooney Horvath argues in his recent book, The Digital Delusion, it may have actually widened the wound of learning resistance. 

Of course, this shouldn’t be surprising. When the educational community does not ask human-centered questions about our technological adoption, we’re bound to use it ways that decenter the humanity of our students. Rather than framing a school’s use of technology around the types of thinkers a society needs to thrive, we looked at efficiency, convenience, and a surface-level type of fun. No wonder we are seeing declining test scores and lower attendance. Why would students go to a school system that tries to compete with social media or online gaming? They can get a cooler version of that outside school walls.

Schools must offer students something better, something more human. 

Last year, I contributed to the CivXNow and EdSafe AI Alliance education policy report, asking in the conclusion what I continue to believe is a fundamental question for those of us in education: “What is education if not the process of making us more human?” This question, as our report cements, does not mean the complete rejection of technology in schools. It does, however, mean we need to redefine the terms of our relationship.

Thankfully, this is already happening. Earlier this year, Los Angeles Unified School District, the second-largest school district in the nation, moved to create a policy to limit screen time across its schools. Whole states are moving in the same direction. Soon, more states and districts will follow suit, which will force us to dramatically rethink the approach we adopted in education during the first quarter of the 21st century. This coming wave demands a reevaluation and recalibration of the use of technology in schools.

Technology can have a beneficial role in the K-12 experience. But it must be limited. Platforms should consider ways to offload a school’s reliance on their technology. To honor the humanity of the students we serve, we must prioritize their intellectual growth over our usage statistics. 

The hammer is a boring but useful tool. More edtech should be too.

Recently, I asked you: where are you feeling most stuck with your fitness right now?

Hundreds of you wrote back. Thoughtful, honest answers. Thank you.

I’m working my way through all of them.

And one theme jumped out at me IMMEDIATELY.

I know what to do. I can’t get myself to start.

One reader, let’s call her Supergirl, said it this way:

“I know what I should be doing, but for whatever reason, I can’t motivate myself to start. I was so disciplined for months, training 3 to 4 times a week, walking 5 days a week. Then I took a break that lasted for a year, and for some reason, I can’t find my way back.”

If you’ve ever had a great run (for a few days or a few years) and then couldn’t find your way back, this one’s for you, too.

From 0 to 70

I’ve heard this so many times in my coaching career. You were in a really good groove. Something knocked you off. And getting back on track feels incredibly difficult, and you don’t know why.

I’ve experienced this myself! I was in a groove with food logging. It felt easy. Then I took a break, and when I tried to start up again, I couldn’t get it going with any consistency for the life of me.

Here’s my take after nearly two decades of coaching: I doubt this is a motivation thing.

I think it’s an on-ramp thing.

You were cruising at 70 miles an hour. You made a pit stop, and now you’re trying to jump the car straight back to 70. Instantly.

Of course that’s going to feel rough!

The Rearview Mirror

Another reader put it really well in their message to me:

“I know how to start (again) but it feels like it’s not enough compared to where I’ve been before.”
After a break, it’s really easy to compare yourself to your previous routine. I should be training 3 to 4 times a week. Walking 5 days. The workouts should look like they did. I know what to do. I just need to do that thing.

 

That’s driving with your eyes on the rearview mirror. And it makes anything smaller feel like it doesn’t count.

But smaller is how you get back up to speed.

After multiple false starts with food logging, I realized I was falling into the same trap. And instead of forcing myself to weigh and measure anything, I gave myself a different on-ramp. Protein and veggies at each meal? Check. That allowed me to build back up again and find the groove that worked for me in this current phase of life.

Previous success can feel like a scorecard that you have to grade yourself against.

But what worked before might not work for you right now.

And it’s important to remember that most of us needed an on-ramp the first time, too. That part didn’t change after some time off.

“Shoulding” All Over Yourself

You know what you “should” be doing. Let’s put that aside for now.

Instead, let’s shrink down what our focus is. We don’t have to figure out the whole routine. Not the whole week. Let’s work on today.

Try this thought experiment with me: if you didn’t have any expectations of what this “should” look like, what is one thing that feels doable today?

Maybe it’s performing your warm-up routine. Or doing the first round of exercises in your workout.

Maybe it’s batch cooking some protein tonight, or running to the grocery store to stock up on some easy fruit and veggie options.

Try it out, and see how that feels. Is the resistance still there? If it isn’t, you’ve found the start of your on-ramp.

And if it still feels hard to start? That’s OK, too. We can choose a different entry point and try again.

—

If you’re in that camp of “I know what to do. I can’t get myself to start,” give yourself a different, smaller on-ramp.

Your on-ramp doesn’t have to be forever.

But it may be exactly what you need right now.

Gardening 101: Aster

📅 Oct 22, 2026  |  Category: Other  |  Read Source →

Aster, Asteraceae: “Divine Daisy”

It is a mildly sad sight at the end of the summer when many plants lose their luster, with flowers fading and leaves looking a bit burned, as if they forgot their sunscreen. But late summer and early autumn is when perennial asters can save the day, and the garden.

Coming up: the most colorful season at Old Court Nurseries in England, a small family-run operation specializing since 1906 in propagating its own Michaelmas daisies (and many other varieties of asters). Photographer Britt Willoughby Dyer visited the nurseries’ Picton Garden at the height of the season:

Photography by Britt Willoughby Dyer.

Above: Old Court Nurseries is located in the Malvern Hills in the English Midlands.

Asters have a deep history in Greek mythology. According to legend, the goddess Astrea created asters with her tears. The story goes that she was so distraught at how few stars appeared in the dark sky that she started crying, and as her tears fell they turned into star-shaped asters on the ground. Aptly named for the ancient Greek and Latin word for star (because of its long, radiating petals), asters are a star of the late-summer garden.

Above: Symphyotrichum ‘Photograph, with small lavender-blue flowers that bloom in October, belongs to a genus in the Asteraceae family.

As other perennials are starting to slow down, asters are winding up to add hints of necessary color. Asters come in a range of colors, including pink, purple, red, and white.

Above: S. novae-angliae ‘Barr’s Purple’.

With more than 600 species in the Aster genus, it also shares the same family as the daisy. Found wild in North America and southern Europe, asters are mainly perennials but a few are annuals and biennials. The two main groups of asters are the New England aster (Aster novae-angliae) and the New York asters (Aster novi-belgii).

While there is a galaxy of asters to choose among, a favorite is Aster frikatii ‘Monch’ for its long bloom time; it grows to a dramatic height of up to three feet and bears large lavender-blue flowers.

Above: Underplant around the bare lower section if you find asters’ nakedness to be a problem.

The downside to asters is they can be tricky when it comes to water. They tend to drop their lower leaves if not kept well-watered in the hotter months. Also, aster plants have a tendency to eventually die out in the center, making them a great candidate to rejuvenate by dividing and replanting in new clumps every two to three years.

Another issue is powdery mildew. If your garden is plagued with mildew in the fall and your asters are afflicted with this punishment, consider planting mildew-free varieties, such as the low-growing variety Aster dumosus. Another solution is to make sure asters have good air circulation around them and plenty of sun.

Above: S. lateriflorum ‘Lady in Black’.

Cheat Sheet

  • Heights vary dramatically, with varieties that range from eight inches to eight feet tall; there is an aster for almost every style of garden.
  • Aster’s flat, central landing pad attracts butterflies; the nectar is a last chance to fuel up before heading south for the winter. Birds and bees also appreciate the flower, and the aster depends on these creatures to pollinate them.
  • With a multitude of purposes, asters are a stunning addition to a wildflower garden, useful in a traditional border, or mingling in a rock garden.

Above: To avoid tumbling flower towers, stake the taller varieties. Also remember to routinely deadhead exhausted flowers and then cut back in the winter after the foliage has declined.

Keep It Alive

  • Grow in full sun or part sun in loamy soil (translation: well-draining but moist) and give asters regular water, especially in the summer.
  • Plant most asters in the spring and amend your soil prior to planting with an organic fertilizer and then mulch with compost to keep the soil cool.
  • While you can grow asters from seed, a more reliable method is to purchase a potted four-inch or one-gallon size from a nursery.

Body doubling: what it is, how it works, and tips to try

📅 Oct 22, 2026  |  Category: Entertainment  |  Read Source →

Clinically reviewed by Dr. Chris Mosunic, PhD, RD, MBA

If you're struggling to focus or get things done, body doubling might help. Explore what it is, why it can boost motivation, and 9 tips to help you try it for yourself.

If you’ve ever opened your laptop to begin your workday from home or checked your mountain of a to-do list and felt zero motivation to tackle it, you’re in good company. On days that you just can’t find the energy or focus to get started, it can help to have a little boost of accountability. 

Body doubling, a phrase that means working alongside another person, has gained popularity over the years and is especially popular among people with attention-deficit/hyperactivity disorder (ADHD). Body doubling (either in person or virtually) is said to help motivate people to stay focused and accountable for the tasks at hand. And while it isn’t a formal treatment or backed by robust clinical research, plenty of people have spoken to its effectiveness.

So, what does body doubling involve, and why do so many people swear by it? More importantly, will it work for you? Pull up a seat and let’s explore what you need to know about the technique, plus a few simple ways to try it out for yourself.

 

What is body doubling?

Body doubling is the practice of working alongside another person to stay focused and complete a task, either in the same space or virtually. According to the ADDA, the term “body doubling” was coined in the late 1990s by ADHD coach Linda Anderson.

The rationale behind body doubling is that having someone else present and engaged in their own task can make it easier to start and stay on track with yours. To be clear, there’s no coaching or collaboration involved. You’re just working next to each other, because a shared presence can create a sense of structure and accountability. 

If you sit at your kitchen table while your roommate does homework, join a silent Zoom session where everyone works on their own projects, or even fold laundry while a friend cleans their space on FaceTime, those are all examples of body doubling.

 

What are the possible benefits of body doubling?

Many people feel that body doubling helps them break through procrastination and maintain momentum,  especially during overwhelming tasks.

Here are four benefits of body doubling:

  • Getting started: Sometimes the hardest part is just beginning. Having someone else nearby can help create a sense of gentle urgency.

  • Staying on task: When another person is focused, it can be easier for you to stay engaged with your own work. 

  • Feeling less isolated: This practice can reduce the emotional friction that builds when you’re feeling alone in your head. 

Creating structure: Knowing someone will be present at a specific time gives your day a natural rhythm. Plus, it can add a layer of accountability.

 

Can body doubling help people with ADHD?

This technique has gained popularity within the ADHD community. While it’s important to note that this isn’t a clinically recommended treatment—and there’s limited research to support it—many people with ADHD do say that it helps them function more consistently. The idea is that having someone nearby provides external structure and co-regulation. 

When your executive functioning is impaired, simple tasks can feel overwhelming. But body doubling creates a soft sense of accountability, which can make it easier to begin and stay engaged in tasks.

With that said, some people find it distracting or feel pressure to “perform,” especially if their partner’s energy doesn’t match theirs. Additionally, if your body double doesn’t understand ADHD, their presence can sometimes feel more frustrating than supportive.

If you’re navigating ADHD, body doubling could be another great tool to add to your toolkit. But only if it feels natural to you. 

Disclaimer: Please note that body doubling isn’t a substitute for medication or therapy for people with ADHD.

 

How to try body doubling: 9 tips to find the right body double for you 

If you find it hard to begin or stay engaged with tasks, body doubling could be the flexible tool you need. To get started, look for someone who matches your energy and who also makes you feel comfortable. 

Here are nine ways you can mindfully add body doubling into your life.

1. Start with low-stakes tasks

If you’re new to body doubling, try it during something that feels manageable, like folding laundry or organizing your desk. This can give you space to experiment without the pressure of a high-stakes deadline or an environment that isn’t familiar to you, like a coworking space or coffee shop.

2. Set expectations upfront

Have a quick conversation about what you both want. Ask the other person if you’ll talk, stay silent, or check in at the end.

Clear expectations help make the experience smooth and more supportive.

💙 Stay on the same page with your coworking partner with guidance from Jay Shetty’s Expectations.

3. Try a silent co-working session

Working alongside others in total silence can be helpful for concentrating and removing social pressure, while still giving you the benefits of shared presence.

Try scheduling a Zoom session where you say hello, then mute yourselves and work independently. You could also start a silent group video call with coworkers and only use the chat to check in.

4. Use ambient or “study with me” videos

If real-time body doubling feels overwhelming or isn’t accessible, consider searching for helpful videos on YouTube or TikTok. 

Search for “study with me” or “body doubling,” and you’ll find creators who film themselves doing everyday tasks. By watching someone else stay focused, it may help you do the same.

 

5. Schedule regular sessions

Whether it’s a weekly Sunday cleaning hour with a friend or a daily Zoom session at 9am, a recurring slot can build structure into your routine. This can be especially helpful if you struggle with executive function challenges.

Related read: Meditation for ADHD: 9 tips and techniques

6. Match energy, not task

You and your body double don’t need to be doing the same thing. One of you could be writing emails while the other is meal prepping or baking a cake. 

What matters most is that the energy feels aligned, focused, and respectful.

Related read: How to focus better: 8 tips to improve concentration

7. Keep it short and specific

Make whatever task you’re doing as manageable as possible. Choose a specific task to start with, and try doing it for 15–30 minutes at first. 

This reduces overwhelm and helps give you a clear finish line.

8. Loop in someone you trust

Some people feel vulnerable doing tasks in front of others, especially ones tied to shame or executive dysfunction. 

So, choose a body double who won’t judge or try to fix you. 

💙 Learn how to build relationships with people you trust during this Mindful Friendships session with Jay Shetty.

9. Adapt to your needs

If you prefer asynchronous support, text a friend when you start a task and again when you finish. On the flip side, if you’re more motivated in groups, explore coworking in community accountability spaces. 

Remember, there’s no one right way to body double. The key is to experiment and adjust based on what feels good to you. 

 

Body doubling FAQs

Is body doubling possible?

Yes. Body doubling only needs one other person who is working at the same time as you. They can be in the room or on a video call. They don’t need to share your task or give you feedback.

Whether it works varies from person to person. Research on body doubling is limited, and many reports come from people who have tried it. Start with one short session and notice if it’s easier to begin and stay on task.

How does body doubling work?

Body doubling works by providing subtle social accountability and structure. When another person is present, your brain registers the shift in environment. This presence can make it easier for you to start a task or stay with it. 

And the accountability can be enough to kickstart momentum, especially if you’re someone who tends to overthink or avoid certain tasks.

Can body doubling help with procrastination?

It can. Procrastination often stems from overwhelm, perfectionism, and decision fatigue. But body doubling can add a sense of time and presence. You can see that there’s someone else there doing their own thing. And, as a result, it can become a little easier for you to start doing your own thing. 

It allows the pressure of the task to lift, even though it may still feel hard. 

Are there any cons of body doubling?

There can be cons of body doubling. Some people find it distracting, especially if the other person wants to talk and you don’t. Additionally, if you have social anxiety or a history of trauma, being observed might make you feel emotionally charged. 

In general, this practice isn’t for everyone. If you’re curious, check in with yourself. Ask if it’s something that would feel supportive and safe. If not, then it’s okay to step back and try a different format.

Is body doubling just for people with ADHD?

Anyone can try body doubling. While the term does have roots in ADHD communities, the technique can be applied to anyone. If you struggle with focus or motivation, this practice might be the thing for you. 

Plus, if you’ve ever gotten more done in a coffee shop than at home, or felt a boost from working silently next to a friend, you’ve already experienced a version of body doubling. 

How can I practice body doubling if I live alone?

You don’t need someone in the same room to try body doubling. Virtual options can be just as effective. You could join a coworking session on Zoom or even stream a “study with me” video in the background. 

That being said, if you’d rather keep it low-contact, text a friend when you’re about to start a task. Then text them again when you finish. The key isn’t the format; it’s the feeling of shared effort and accountability. So, do whatever feels right to you.
